# ホークアイのボード

大介さんのタスクの置き場と、朝の報告を表示するページ。

- URL：https://claude.ai/artifact/BArqEJsoCdha4s8zXcibPS
- 公開範囲：非公開（大介さん本人だけ）。共有はしない
- 元のページ（HTML）：Artifact に保存されている版が正。直すときは Artifact ツールで `read` してから、同じ URL に `publish` する
- データの読み書き：`ArtifactData` ツール（`url` に上の URL を渡す）

## データベースの形

### `tasks`（タスク。1件 = 1ドキュメント）
- doc_id：自由（ボードから追加したものは自動の英数字。ホークアイが入れるときは `t-YYYYMMDD-連番` などでよい）

| 項目 | 型 | 値の決まり |
|---|---|---|
| `title` | 文字 | タスクの名前（必須） |
| `due` | 文字 | 期限 `YYYY-MM-DD`。なければ `""` |
| `status` | 文字 | `未着手`／`進行中`／`完了` のどれか |
| `priority` | 文字 | `高`／`中`／`低` のどれか |
| `category` | 文字 | 区分。標準は `自分`／`鈴木さんMTG`／`事務所`／`個人`。新しい区分は自由に足してよい（ボードの絞り込みに自動で出る） |
| `memo` | 文字 | メモ。なければ `""` |
| `createdAt` | 文字 | 作成日 `YYYY-MM-DD` |
| `completedAt` | 文字 | 完了日 `YYYY-MM-DD`。未完了なら `""` |
| `updatedAt` | 文字 | 最終更新の日時（ISO 8601） |
| `source` | 文字 | 入れたところ。`board`（画面から）／`hawkeye`（毎朝の自動実行）など |

- 完了にするときは `status: "完了"` と `completedAt` を一緒に入れる。戻すときは `status: "未着手"`、`completedAt: ""`
- 既にあるドキュメントを書き換えるときは、読んだときの `version` を `if_version` に渡す（大介さんが画面で直した内容を上書きしないため）
- ボードの表示：期限切れ／今日／今週（日曜まで）／それ以降／期限なし／完了（「完了も表示」のときだけ）

### `reports`（朝の報告。1日 = 1ドキュメント）
- doc_id：日付 `YYYY-MM-DD`

| 項目 | 型 | 値の決まり |
|---|---|---|
| `date` | 文字 | 報告の日付 `YYYY-MM-DD`（doc_id と同じ）。ボードはこの項目の新しい順に表示する |
| `body` | 文字 | 報告の本文。プレーンテキスト（改行はそのまま表示される） |
| `generatedAt` | 文字 | 書き込んだ日時（ISO 8601） |

- ボードの上部に最新の1件を表示し、「前の日」で過去14日分までさかのぼれる
- 今日の分がまだないときは「今日の報告はまだです」と出る

## 画面の構成（2026-11-06 ダッシュボード化）
上から順に、スマホで30秒で見られる並びにしている。
1. 数字のタイル：期限切れ／今日／今週／進行中／未着手（`tasks` から数える。期限切れが1件以上なら赤）
2. 「今日やること」と「今日の予定」のカード（今日の `reports` の本文から取り出す）
   - 今日の報告がまだのときは、「今日やること」にボードの期限・優先度から選んだ候補を3つまで出す
3. 朝の報告の残りの見出し（1見出しが1カード）。「前の日／次の日」で過去の報告に切り替える
4. 期限の近いもの：遅れと今後14日の、未完了の件数を日ごとの棒で表示。棒を押すと、その日のタスクが出る
5. 区分ごと（未完了の件数）・状態ごと（完了は直近7日）の小さな横棒グラフ
6. タスクの追加欄、区分の絞り込み、タスクのカード（優先度・区分・期限・状態を色付きのラベルで表示）

### 完了の扱い（2026-11-06 追記）
- チェックを押すと `status: "完了"`、`completedAt` に今日の日付が入る。カードはその場に残り、薄くなって取り消し線が付く
- もう一度押すと元に戻る（`completedAt: ""`）。同じ画面で進行中から完了にしたものは `進行中` に、それ以外は `未着手` に戻る
- 完了したものは、完了した日のあいだだけ一覧に残る。翌日（`completedAt` が今日より前）からは一覧から消え、「完了も表示」を押したときだけ「完了（前日まで）」に出る
- 数字のタイルと図は、完了したものを除いて数える。タイルの下に「今日完了 n件」を出す
- 画面からの書き込みは、ページ用のデータベースの仕組みに `if_version` がないため、後から書いたほうが残る。毎朝の自動実行（`ArtifactData`）は今までどおり `if_version` を付ける

### 表示の速さの工夫（2026-11-06 追記）
- 外から読み込むものはない（Google Fonts をやめ、OS の標準フォントにした。図は CSS で描いている）
- 前回のタスクと報告（最新3件）をブラウザの localStorage に保存しておき、開いたらすぐそれを出す。その間は「前回の内容（日時）を表示中」と出し、データベースの最新が届いたら描き直す。保存の読み書きに失敗しても、何も出さずに先へ進む
- `tasks` と `reports` は同時に読みに行く。`reports` は最新7件だけを読む
- localStorage はボスが使っているブラウザの中だけに残る（ほかの人や端末には行かない）

### `reports` の `body` の書き方（画面が見出しで区切って表示するため）
- 見出しは1行に `【見出し】` と書く（`■見出し`、`## 見出し` でも可）
- 項目は `・` で始める（`1.` `-` でも可）
- 見出しの名前に「今日やること」を含む節は、先頭の3項目を「今日やること」カードに出す
- 見出しの名前に「予定」を含む節は「今日の予定」カードに出す。項目の頭に `08:00-09:00` や `終日` があれば、時刻の列に分けて表示する
- それ以外の見出し（例：【期限が近いもの・遅れているもの】【メンバーの状況】【日報のまとめ】）は、1見出しを1カードにして表示する
- 例：
  ```
  【今日の予定】
  ・08:00-09:00 MG朝礼会
  【今日やること】
  1. 〇〇
  【期限が近いもの・遅れているもの】
  ・〇〇（2日遅れ）
  ```
