# ホークアイ 毎朝の手順

## 実行のタイミング
- 毎日 7:00 までに報告（土日も）（2026-11-06 大介さん決定）。定期タスク「ホークアイ朝の報告」が 6:50 に動く

## タスクの置き場
- ホークアイのボード：https://claude.ai/artifact/BArqEJsoCdha4s8zXcibPS
- タスクはボードのデータベースの `tasks`、朝の報告は `reports`（doc_id は日付 `YYYY-MM-DD`）
- 項目の形と値の決まりは `hawkeye/board.md`
- 読み書きは `ArtifactData` ツールで行う

## 手順
1. Googleカレンダー（d-yamashita@act-cess.jp）の今日・明日の予定を読む
2. ボードのデータベースからタスクを読む（`ArtifactData` の `list`、コレクション `tasks`）。`status` が `完了` でないものから、次を拾う
   - 期限を過ぎたもの（`due` が今日より前）／今日が期限のもの
   - 今週（日曜まで）が期限のもの
   - 進行中のもの
3. 「今日やること」を3つまでに絞る（期限・優先度と予定の空き時間から提案。決めるのは大介さん）
4. （段階2・3）チャットワークの指定ルームから、メンバーの予定の写真と日報のコメントを読む（`hawkeye/chatwork.md` の準備ができている場合だけ）
5. 今朝のニュースと税務の重要トピックを拾う（2026-11-06 大介決定）
   - Web検索で、その日の朝刊・朝のニュースから大きなトピックを3つ選ぶ（国内の経済・政治・社会を中心に。経営者が知っておくべきものを優先）。各1行の要約と、出どころ（報道機関名）を付ける
   - 税務に関する重要事項（税制改正の動き、国税庁の発表、申告・納付の期限に関わること など）があれば、別の見出しで挙げる。なければ「特になし」と書く
   - 税務のトピックは事実の紹介にとどめ、「要確認」を付ける。個別の判断や解釈は書かない（判断は資格者が行う）
   - 有料記事の本文は写さない。見出しと要旨だけにする
6. 朝の報告を `reports` に書き込む（`ArtifactData` の `set`、doc_id は今日の日付、項目は `date`・`body`・`generatedAt`）。同じ日の分が既にあれば、読んだ `version` を `if_version` に渡して上書きする
7. タスクの追加・状態の変更は、大介さんが頼んだとき、または予定から明らかなときだけ行う（削除はしない）

## 朝の報告の形
- 今日の予定（時刻順）
- 今日やること（3つまで）
- 期限が近いもの・遅れているもの
- 今朝のニュース（3つ）
- 税務の重要トピック（あれば。なければ「特になし」）
- （段階2）メンバーの今日の行動と明日の予定
- （段階3）日報のコメントのまとめ

`body` はプレーンテキストで書く。見出しは【今日の予定】のように角かっこで区切り、項目は「・」で始める。見出しは【今朝のニュース】【税務の重要トピック】を使う。予定とタスクの部分は30秒で読める長さにし、ニュースは1項目1行にする。顧問先の名前はボードの報告には書いてよいが、このリポジトリのファイルには書かない。
