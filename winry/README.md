# ウィンリィ：子どものサッカーの記録

大介の子どものサッカー（試合・大会・練習）の記録を置くフォルダ。

## 記録のルール
- 結果・得点・出来事は、ボス（大介）が言ったこと・見せたものだけを書く。推測したもの（試合の順番、相手など）には「（要確認）」を付ける
- 子どもの名前は、このフォルダの中では書いてよい（家族の記録のため）
- **このフォルダの中身は外に出さない。** エドの記事・SNS・講演などに使うときは、名前・学校・所属チームを出さない（daisuke-clone の家族の情報のルールに従う）。顔が写る写真は保存しない
- 相手チームの選手・保護者の名前は書かない
- 比べる言い方・責める言い方はせず、できたこと・挑戦したことを書く

## ファイル
- `matches/YYYY-MM-DD_大会名.md`：その日の試合表・結果・得点・出来事（1日1ファイル）
- `matches/` の画像：大会の対戦表など（顔が写るものは置かない）
- `season.md`：通算の記録（試合数・勝敗・得点）
